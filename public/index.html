📖 AI Bridge — Community Guide & Quickstart

Everything you need to connect your local AI coding agent with Google AI Studio, Gemini Web, ChatGPT, or Claude without paying for API tokens.

🧩
1. Install Chrome Extension (2 Minutes)
  1. Open Google Chrome and navigate to: chrome://extensions
  2. Enable "Developer mode" in the top-right corner.
  3. Click "Load unpacked" in the top-left corner.
  4. Select the extension/ folder inside this project directory.
  5. The extension badge will turn ON when the server is running on localhost:3388.
⚡
2. Google AI Studio & Multi-Chat Support

AI Bridge is built to talk with any web AI chat interface. You can select your platform from the dropdown or enter a custom link:

  • Google AI Studio App Builder (aistudio.google.com/apps): Full application generation with Gemini 2.5 Pro.
  • Google AI Studio Playground (aistudio.google.com/prompts/new_chat): Unlimited context playground.
  • Google Gemini Web (gemini.google.com/app): Direct reasoning with visual media upload support.
  • ChatGPT & Claude (chatgpt.com, claude.ai): Full multi-model flexibility.
  • Custom Website Link: Any local or remote LLM web interface.
💻
3. Local Files vs Multi-VPS Remote Mode

Do you need a VPS? Absolutely NOT!

  • Local Mode (Default): Point AI Bridge to your project folder on your Windows/Mac/Linux computer. Generated code is syntax-checked and written directly to your local files.
  • Multi-VPS Mode: If you have remote deployment servers, add SSH profiles in the Settings & VPS tab. AI Bridge can upload files via SFTP and trigger pm2 restart automatically.
🤖
4. Connect External AI Coding Agents

Any agent (Google Antigravity, Cursor, Windsurf, Claude Code, Aider, CLI) can use AI Bridge as a sidecar without needing API keys:

Dispatch a task from any agent or terminal:
curl -X POST http://localhost:3388/api/task/dispatch \
  -H "Content-Type: application/json" \
  -d '{
    "goal": "Refactor authentication middleware with JWT validation",
    "chatUrl": "https://aistudio.google.com/apps"
  }'
Retrieve generated code and code blocks:
curl http://localhost:3388/api/handoff/latest
🛡️
5. Anti-Regression Feature Guard

When applying code to an existing file, AI Bridge automatically scans both versions before writing:

  • Extracts functions, React hooks, imports, components, and API routes.
  • Calculates a preservation score.
  • Blocks accidental truncations or drops with a regression warning.
  • Validates syntax via node --check.
🔒
6. Privacy & Open Source Guarantee

This software is 100% open-source under the MIT license:

  • Zero telemetry, zero tracking, zero third-party reporting.
  • All passwords and SSH keys are stored locally on your machine in config.json (gitignored).
  • Ready to publish, clone, and fork on GitHub.
